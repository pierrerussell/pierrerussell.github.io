BizModSwapBot

A Telegram Mini App for NUS students to swap module slots efficiently with automated matching logic.

GitHub Repository: github.com/pierrerussell/BizModSwapBot

Project Overview

The Problem

Students at the National University of Singapore (NUS) often face challenges in securing their preferred sectional or tutorial slots. Manual swapping via chat groups is inefficient, hard to track, and prone to communication breakdowns.

  • Manual searching through endless chat messages
  • No automated way to find matching swaps
  • Difficulty managing multiple swap requests
  • Everyone double sending their swap requests

The Solution

BizModSwapBot provides a streamlined, automated platform integrated directly into Telegram.

  • Simple UI to post current and desired slots
  • Automated matching engine to find potential swaps
  • Native mobile experience as a Telegram Mini App
  • Secure authentication using Telegram's native system
  • Management dashboard for all your swap requests
